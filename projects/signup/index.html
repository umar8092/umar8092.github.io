Signup enrichment agent

Every time someone signs up for a customer's product, this agent researches them automatically, so the sales team opens the CRM to a complete brief instead of a bare email address.

How it works

  1. Trigger: New signup (in the customer's product)
  2. Enrich: Apollo (person and company data)
  3. Augment: Web search (context on the company), Traffic data (website traffic signals)
  4. Think: AI agent (merges everything into one intelligence note)
  5. Deliver: Customer's CRM (note written to the lead record)

What I built

  • Runs on every new signup with no manual step
  • Enriches each lead through Apollo, then adds web search and website traffic data
  • Uses an AI step to consolidate all sources into a single, readable intelligence note
  • Writes the note back to the lead in the customer's CRM

Stack

  • Apollo
  • Web search
  • Traffic data
  • AI
  • CRM
