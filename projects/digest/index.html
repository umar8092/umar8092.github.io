Daily shipped-work digest

Replaced manual daily ship-tracking with one automated message: what shipped in the last 24 hours, tied to the tickets it was for.

How it works

  1. Schedule: Daily run
  2. Last 24 hours: GitHub commits, Bitbucket commits
  3. Join: Linked ClickUp tickets (each commit matched to its ticket)
  4. Post: Slack (consolidated shipped-work digest)

What I built

  • Aggregates the last 24 hours of commits from GitHub and Bitbucket
  • Joins each commit to its linked ClickUp ticket
  • Posts a single consolidated digest to Slack every day

  • Bitbucket
  • ClickUp
  • Slack
